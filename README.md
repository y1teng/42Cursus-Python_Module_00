# 42Cursus-Python_Module_00

Exercises for 42's Python Module 00.

| Exercise | File | Description |
|---|---|---|
| ex0 | `ft_hello_garden.py` | Prints a static greeting, "Hello, Garden Community!". |
| ex1 | `ft_garden_name.py` | Prompts for a garden name and prints it back. |
| ex2 | `ft_plot_area.py` | Prompts for a plot's length and width and prints the computed area. |
| ex3 | `ft_harvest_total.py` | Prompts for three days of harvest counts and prints their sum. |
| ex4 | `ft_plant_age.py` | Prompts for a plant's age in days and reports whether it's ready to harvest (> 60 days). |
| ex5 | `ft_water_reminder.py` | Prompts for days since last watering and reminds the user to water if it's been more than 2 days. |
| ex6 | `ft_count_harvest_iterative.py` | Prompts for a number of days and counts down to harvest using a `for` loop. |
| ex6 | `ft_count_harvest_recursive.py` | Recursive variant of the harvest countdown. |
| ex7 | `ft_seed_inventory.py` | Takes a seed type, quantity, and unit (packets/grams/area) and prints a formatted inventory line. |
